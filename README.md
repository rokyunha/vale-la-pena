# ¿Vale la pena?

Una app chica para el celular que te ayuda a no decidir por impulso:

- **Trabajo:** cinco preguntas antes de sumar una herramienta o un servicio.
- **Compras personales:** cinco preguntas antes de comprar algo.
- **Tareas:** la matriz de Eisenhower (hacer, programar, delegar, eliminar).

Ábrela en el celular y agrégala a la pantalla de inicio. Funciona sin internet.

**Tus datos:** el historial se guarda solo en tu navegador. No hay cuentas ni servidores, y nadie más
lo ve. Si borras los datos del navegador o cambias de celular, se pierde: usa *Historial › Respaldo*.
